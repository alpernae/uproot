    Privacy

    Windows components that collect, stage or upload your activity and diagnostic data — telemetry services, scheduled tasks and the activity-history / error-report stores on disk. Removal is backed up like everything else: services export to .reg, tasks export to .xml, files go to quarantine (or are deleted permanently if you choose).

    Press Scan to inventory the telemetry and activity items on this system.

    Shared runtimes

    Redistributables like Visual C++, .NET and Java are installed by many applications at once. The analyzer reads the import tables of every installed program and shows which runtimes still have dependants. Removing a runtime that shows no dependants is a suggestion only — drivers and other software can use these silently.

    Quarantine

    Removed files are held here rather than destroyed, so a mistake stays reversible. Registry keys are always exported to .reg backups first.
